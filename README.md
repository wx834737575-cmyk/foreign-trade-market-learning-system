# 外贸与投资决策系统

一个面向 Windows 的本地优先、证据驱动的外贸与市场学习系统。

## 为什么做它

信息爆炸时代里，二手信息、碎片化知识和未经核验的结论很容易混在一起。很多人即使愿意查一手资料，也不知道官方信息应该去哪里找，或者会被较深的网页入口、分散的发布目录和不同的数据口径挡住。这个项目是一个个人学习实验：先阅读金融和经济理论，再通过整理过的官方来源入口连接一手数据，记录自己如何解读指标、形成判断，并在一段时间后回看判断是否准确。它把“找到来源 → 理解口径 → 观察真实数据 → 写下假设 → 等待结果 → 复盘修正”变成可以重复执行的工作流，也帮助学习者降低寻找和使用一手信息的门槛。

项目提供证据、规则和复盘工具，不替代用户作最终投资或经营决策，也不执行交易。

## 当前能力

- 建立可审计的数据来源、原始证据、历史版本和质量状态模型；
- 提供中文 Dashboard、数据日历、来源中心和分析笔记；
- 提供人民银行 M0/M1/M2、国家统计局指标、汇率和航运指数的接入与解析骨架；
- 为外贸渠道数据预留统一的观察和复盘模型；
- 默认通过 Windows 桌面快捷方式启动，并只监听本机地址。

## 学习闭环

```text
官方来源 → 原始证据 → 解析与校验 → 指标与透明计算
       → 个人假设与信心等级 → 经过一段时间后的结果 → 复盘与修正
```

## 开源范围

本仓库发布可复用的代码、测试、文档和不含隐私的示例配置。个人数据库、原始证据、客户资料、业务渠道导出、未公开笔记、日志、备份和凭据不在仓库内。数据来源和再分发边界见 [DATA-SOURCES.md](DATA-SOURCES.md)，本地部署边界见 [SECURITY.md](SECURITY.md)。

项目仍在建设中。人民银行与国家统计局已核验指标会显示绿色质量状态和原始证据哈希；其他模拟数据必须显示“演示数据”标记，未经来源核验的数据不得用于经营或投资判断。

人民银行货币供应量从统计总页自动发现年度文件，以官方 XLSX 为主数据、HTML 逐项交叉核验。2025 年 M1 口径修订以及人民银行发布的 2024 年可比回溯值按不同版本保存，旧口径原值不会被删除。

## 本地运行

### 后端环境

1. 安装 Python 3.12 或更新版本。
2. 运行 `scripts\首次安装.cmd`。脚本会创建项目专用环境、安装后端依赖并运行后端测试。

### 前端构建

1. 安装 Node.js 和 pnpm。
2. 进入 `frontend` 目录并运行 `pnpm install`。
3. 运行 `pnpm build`，生成供 FastAPI 提供的 `frontend\dist`。
4. 回到项目根目录运行 `python launcher.py`，或运行 `scripts\创建桌面快捷方式.ps1` 后使用桌面快捷方式。

公开仓库不提交 `frontend\dist`、数据库或原始证据；首次运行前需要在本机生成它们。若只开发前端，可运行 `pnpm dev`，其 API 请求会代理到本机的后端服务。
