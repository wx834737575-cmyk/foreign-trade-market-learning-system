# V1.0 验收门槛

## 数据

- 每条正式观测值可追溯到来源和原始证据。
- 发布值、修订值和抓取时间能够区分。
- 同比、环比和剪刀差公式有边界测试。
- 官网失败、格式变化或断网不会污染数据库。
- 旧数据、模拟数据和待核验数据有醒目标记。

## 产品

- 首页、指标详情、来源中心、数据日历、业务渠道和分析笔记均可使用。
- 所有核心卡片可进入来源、历史和计算说明。
- 数据状态与环境判断状态分开显示。
- 中文界面不存在碎片化表达或难以理解的英文操作项。

## Windows 交付

- 安装后可从桌面快捷方式启动。
- 用户无需单独启动 Python、Node 或数据库。
- 可以备份和恢复数据库、证据与笔记。
- 可以查看更新日志和失败原因。
