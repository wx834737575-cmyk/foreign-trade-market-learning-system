# 产品需求基线 V1.0

## 产品定位

本项目不是普通数据看板，而是长期使用的个人商业决策系统。它通过“官方证据—规范数据—透明计算—参考信号—个人判断—事后复盘”形成闭环，同时服务外贸经营、宏观学习和未来投资研究。

## 核心使用场景

1. 阿里巴巴国际站客户开发、市场选择、报价和订单环境判断。
2. 未来接入中国制造网并进行跨平台比较。
3. 2026 年底计划上线的独立站，从上线前开始设计访问与转化数据标准。
4. 汇率、航运、海外需求和国内生产环境的联合观察。
5. 保存月度判断、依据、信心等级、实际结果和修订记录。

## 不可妥协原则

- 来源与指标对口，优先官方或依法授权的行业权威来源。
- 每条数据保留统计期、发布时间、抓取时间、单位、口径、原始链接和证据指纹。
- 原始发布值与修订值并存，不静默覆盖。
- 数据质量状态和业务判断状态分离。
- 自动化失败时保留旧数据并明确标为过期，不用旧值冒充新值。
- 自动判断必须公开指标、阈值、方向、期限和限制。
- 不直接预测股票涨跌，不推荐具体股票。
- 中文优先，专业术语提供通俗解释。

## 多渠道经营模型

三类正式渠道：阿里巴巴国际站、中国制造网、独立站。

公共漏斗：曝光/访问 → 询盘 → 有效线索 → 报价 → 谈判 → 成交 → 复购。

独立站扩展字段：流量来源、UTM 参数、搜索词、着陆页、产品页、表单、邮件/WhatsApp 点击、广告成本、隐私同意状态。

## V1.0 首发范围

- 中文 Dashboard 与指标详情；
- 来源中心、数据日历、更新日志；
- 人民银行 M0/M1/M2、同比、环比、M1-M2 剪刀差；
- 可扩展的指标、来源、证据、版本和质量模型；
- 多渠道业务录入框架；
- 分析笔记与事后验证；
- 本地数据库、备份恢复和 Windows 启动入口。

## 非目标

- V1.0 不承诺所有来源全自动；
- 不把第三方聚合站作为关键指标的唯一来源；
- 不在没有平台授权的情况下绕过登录或反爬机制；
- 不把相关性包装为因果关系；
- 不建设公开网站或多用户权限系统。
