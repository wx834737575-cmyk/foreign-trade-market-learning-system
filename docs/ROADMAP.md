# 完整开发路线图

## 阶段 0：产品与证据基线（已完成）

冻结产品定位、三类业务渠道、官方来源原则、数据质量状态、证据链和 V1.0 验收门槛。

## 阶段 1：可运行骨架（已完成）

建立本地 FastAPI + React + SQLite 架构，完成中文 Dashboard、来源中心、数据日历、业务渠道、分析笔记和 Windows 启动入口。

## 阶段 2：官方数据纵向样板（进行中）

先把人民银行货币数据和国家统计局 PMI 做到“官方页面—原始证据—哈希—解析—校验—版本化观测值—Dashboard”全链闭环，再扩展到海关、汇率和航运。

## 阶段 3：个人业务数据

接入阿里国际站脱敏导出；预留中国制造网同口径导入；在独立站上线前完成 UTM、事件、表单、线索 ID、隐私同意和备份规范。统一比较访问/曝光、询盘、有效线索、报价、订单、收入和获客成本。

## 阶段 4：决策与学习闭环

增加指标详情、口径解释、规则版本、证据引用、月度分析、信心等级、反例、验证日期、实际结果和修订原因。系统提供证据与规则，不代替用户作最终决策。

## 阶段 5：自动更新与运维

增加更新调度、失败日志、数据过期提醒、Windows 通知、每日备份、恢复演练、数据库迁移和更新日志。自动更新失败时保留最后一次已核验值并明确显示过期状态。

## 阶段 6：V1.0 交付

完成 Windows 打包、桌面快捷方式、首次安装向导、无开发工具运行测试、断网与官网改版测试、备份恢复测试、整机迁移测试和最终使用手册。

## 后续长期版本

- V1.1：海关分市场/分品类分析和报价辅助。
- V1.2：阿里国际站、中国制造网、独立站跨渠道漏斗。
- V1.3：宏观指标学习路径与复盘评分。
- V2.0：股票研究框架，严格区分事实、估值假设、情景和个人判断，不提供自动荐股。
